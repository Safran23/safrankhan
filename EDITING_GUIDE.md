# Quick Editing Guide

- Edit homepage content in `index.html`
- Edit news posts in `news.html`
- Edit publications in `publications.html`
- Edit conferences in `conferences.html`
- Edit contact information in `contact.html`
- Replace project or news images inside `assets/`
- Adjust fonts, colors, spacing, and layout in `assets/styles.css`

## Common updates
- Replace the profile image: `assets/profile.png`
- Replace the CV file: `assets/Safran_Khan_CV.pdf`
- Add a new project: duplicate one of the `<article class="project-card">` blocks in `index.html`
- Add a new news item: duplicate one of the `<article class="news-card">` blocks in `news.html`
