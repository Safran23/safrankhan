# Safran Khan Academic Website (Rebuilt Version)

Static academic website prepared for GitHub Pages and a future custom domain.

## Pages
- `index.html` — home, About Me, research interests, education, and projects
- `news.html` — academic milestones and news posts
- `publications.html` — journal articles and manuscripts
- `conferences.html` — conference presentations and posters
- `contact.html` — contact information and academic links

## Assets
- `assets/profile.png` — profile photo
- `assets/Safran_Khan_CV.pdf` — CV
- `assets/project-*.png` — project images
- `assets/news-*.jpg/png` — news images
- `assets/styles.css` — website styling
- `assets/site.js` — dark/light mode toggle

## Domain and SEO notes
When you buy a custom domain such as `safrankhan.com`, update the GitHub Pages repository settings with the domain and then submit the site to Google Search Console.
